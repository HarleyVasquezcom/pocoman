HOW TO PLAY

  • Goal — push every treasure box onto a glowing mark.
  • Push only — you can push a box but never pull it. Plan ahead!
  • One at a time — only one box per push; boxes block each other.
  • Stuck? — a box shoved into a corner is usually lost. Undo (Z) or Restart (R).
  • Par — the fewest pushes needed. Shown only when the solver proved it.
  • Solve — press F to auto-play the stored solution.
  • 1000 levels — 9 tiers from Easy to Master. Boards grow, boxes multiply, and layouts twist from open rooms into braided mazes and packed chambers.
